# References

Projects that are useful to compare with or learn from. Local clones live in `references/`, which git ignores.

- [Omni Describer](https://github.com/audioses/omni-describer): a Windows desktop app that generates audio descriptions for local videos or YouTube links with Google Gemini, lets the user review and edit the script, and exports the video with the description track mixed in. Clone: `references/omni-describer`.
